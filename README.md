## What this does

The rank and spectrum of the Quantum Fisher Information Matrix (QFIM) are established diagnostics of a circuit's *effective dimension* — its practical capacity, distinct from raw parameter count (Abbas et al., 2021, *Nature Computational Science*). This repository turns that theory into three concrete workflow steps:

| Step | What you get | When to use |
|------|-------------|-------------|
| **1. Quantum reconnaissance** | Point-wise QFI sensitivity map of your dataset | During EDA, before training |
| **2. Architecture screening** | Mean diagonal QFI vs. depth/layers | When choosing between ansätze |
| **3. Degeneracy check** | Per-parameter sensitivity hierarchy (RY vs. RZ etc.) | When a circuit seems "stuck" |

All computations run on `default.qubit` — a classical state-vector simulator. **No QPU access required.**

## Usage

```bash
python qfi_diagnostics.py

This will:
Compute the QFIM for three circuit scales on a toy make_moons dataset:
Toy: 2 qubits × 2 layers (8 params)
Standard NISQ: 4 qubits × 3 layers (24 params)
Deep NISQ: 6 qubits × 4 layers (48 params)

Print a metric summary table (effective dimension, spectral gap, participation ratio, barren-plateau risk) to the console.
Run a depth scan (fixed 4 qubits, varying layers: 1→2→3→4→6) to plot diminishing returns.
Compute SVM correlation (Pearson & Spearman) between per-point QFI and distance to decision boundary.

## Key metrics (computed by the script)

| Metric                      | Meaning                                                                                 |
| --------------------------- | --------------------------------------------------------------------------------------- |
| **Parameters**              | Total trainable parameters (2 per qubit per layer)                                      |
| **$d_{eff}$**               | Effective dimension: rank of QFIM above threshold `1e-6`                                |
| **$d_{eff}$ / $N$**         | Fraction of "live" parameters                                                           |
| **Mean sensitivity**        | `trace(QFIM) / N`. The correct way to compare circuits with different parameter counts. |
| **Spectral gap**            | Ratio of largest to smallest non-zero eigenvalue                                        |
| **PR / $N$**                | Participation ratio flatness. Approaching 1.0 signals barren plateau.                   |
| **Cross-layer correlation** | Mean absolute off-diagonal correlation between different layers                         |
| **Condition number**        | $\lambda_{max} / \lambda_{min}$                                                         |
| **BP risk**                 | `LOW` / `MEDIUM` / `HIGH` / `CRITICAL` (heuristic based on spectral gap and PR/N)       |

Note: Exact numeric values depend on random seed and PennyLane version. Run the script to obtain the current values for your environment.

## Verified results from the article
On make_moons (24 points, noise=0.15, seed=42):

| Observation                                                                  | Value                                                                                                |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Pearson correlation** (QFI sensitivity vs. SVM decision-boundary distance) | **0.55** (p ≈ 0.005)                                                                                 |
| **Spearman correlation** (rank-based, robust to non-linearity)               | **0.36** (p ≈ 0.08)                                                                                  |
| **Mean sensitivity range** across all tested configurations                  | **0.727 – 0.886**                                                                                    |
| **Barren-plateau risk**                                                      | **Not detected** (all mean sensitivities ≫ empirical threshold 0.05)                                 |
| **Depth-scan returns** (fixed 4 qubits, adding layers)                       | **+11.2%**, **+3.5%**, **+3.2%**, **+2.6%** — classic diminishing-returns curve                      |
| **Parameter hierarchy** (Standard NISQ)                                      | **RY rotations dominate RZ** due to Bloch-sphere geometry: RZ sensitivity ∝ Var(σz) drops near poles |

## Methodology in 30 seconds
We encode classical features into qubit rotation angles (angle encoding) and pass them through a hardware-efficient ansatz with data re-uploading and entangling layers. This produces a parameterized pure state |ψ(θ, x)⟩.
The QFIM is computed with respect to this state, not the final measurement. The QNode returns ⟨ψ|Z|ψ⟩ only because PennyLane's gradient machinery requires a scalar output — the QFIM itself is independent of the observable for pure states.

## Honest scope note
This repository is a single-seed, single-dataset illustration of the idea, not a validated benchmark. The toy sample (24 points) is sufficient to obtain contentful, statistically checkable numbers, but not sufficient to treat the conclusions as universal.
For a production pipeline you should:
- Average across multiple random seeds and initializations.
- Test on datasets of realistic size.
- Cross-validate the QFI-to-difficulty correlation on your specific domain.
